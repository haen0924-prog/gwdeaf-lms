👥 직원 관리

여기서 저장하면 [직원목록] 시트에 반영됩니다. PIN은 암호화되어 관리자도 볼 수 없습니다. 직원이 PIN을 잊으면 해당 줄의 PIN 칸에 새 번호를 입력하고 저장하세요. (비워두면 기존 PIN 유지, 새 직원은 필수)
이름 PIN 부서 직위 연락처 역할 담당 선임 시급(원) 기본 연차 주간 근무시간 비고 슬랙 ID
불러오는 중...
· 역할 — 선임: 담당 직원(후임)의 휴가·시간외·대체휴무를 승인/반려하고 시수·대체시수를 확인합니다. (직원 쪽 '담당 선임'에 선임 이름을 지정)
· 슬랙 ID — 선임만 입력합니다. 후임이 신청하면 이 슬랙으로 DM이 갑니다. (슬랙 프로필 → ⋮ → 멤버 ID 복사, U로 시작) 봇 토큰은 [기관 설정]에서 한 번만 등록합니다.
· 담당 선임이 비어 있는 직원의 신청은 승인할 사람이 없어 '대기'로 남습니다. 관리자는 승인/반려하지 않습니다.
· 기본 연차 — 매년 기본으로 주는 연차. 특정 연도만 다르게 주려면 [연차 관리]에서 입력합니다.
· 주간 근무시간 — 단축근무자만 입력(예: 30). 비워 두면 기본 40시간으로 시간외 수당을 계산합니다.

코드를 고치지 않고 여기에서 바꿉니다. ([설정]·[결재설정] 시트에 저장됩니다)
기본 정보

🔐 관리자 비밀번호는 구글 시트의 [설정] 시트 → 관리자비밀번호 칸에서 바꿉니다.
직원 접속 링크
이 링크를 직원들에게 보내면 연결 주소를 따로 입력하지 않고 바로 로그인 화면이 열립니다.
연결 주소
🔔 슬랙 알림 (후임이 신청하면 선임에게 DM)
휴가 · 시간외(사전신청·보고서) · 대체휴무 · 시수 · 대체시수를 후임이 신청/보고하면, 그 직원의 담당 선임 슬랙 DM으로 알려 줍니다.
① api.slack.com/apps → Create New App → From scratch (우리 슬랙 워크스페이스 선택)
② OAuth & Permissions → Bot Token Scopes에 chat:write, im:write 추가 → Install to Workspace → Bot User OAuth Token(xoxb-…) 복사
③ 아래에 붙여넣고 저장 → [직원 관리]에서 선임의 슬랙 ID(프로필 → ⋮ → 멤버 ID 복사) 입력·저장 → 테스트
📋 결재라인 (전체 신청서 공통)
휴가·시간외·시수·대체휴무·대체시수 — 모든 신청서를 인쇄할 때 결재란과 수신처(OOO 귀하)에 공통으로 들어갑니다. 직원의 부서명과 같은 줄이 적용되고, 없으면 첫 줄이 적용됩니다.
